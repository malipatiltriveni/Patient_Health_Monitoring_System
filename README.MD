🏥 PATIENT HEALTH MONITORING SYSTEM
A web-based Patient Health Monitoring System developed using Python Flask, SQLite, HTML, CSS, and JavaScript. The system helps patients monitor important health parameters through a simple and user-friendly dashboard.
FEATURES
🔐 Patient Login
👤 Patient Information
🩸 Blood Pressure Monitoring
❤️ Heart Rate Monitoring
🫁 Oxygen (SpO₂) Monitoring
🌡️ Temperature Monitoring
🩸 Blood Glucose Monitoring
🦋 Thyroid (TSH) Monitoring
📊 Latest Health Information
📋 Previous Health Records
⚠️ Automatic Health Status
🔄 Refresh Health Records
🚪 Logout
💾 SQLite Database
TECHNOLOGIES USED
Python
Flask
Flask-CORS
SQLite
HTML5
CSS3
JavaScript

HOW TO RUN
Install the required packages using:
pip install -r requirements.txt
Run the application:
python app.py
Open the application in your browser:
http://127.0.0.1:5000⁠�
HEALTH PARAMETERS
Blood Pressure – mmHg
Heart Rate – BPM
Oxygen Level – % SpO₂
Temperature – °C
Glucose – mg/dL
Thyroid (TSH) – mIU/L
DISCLAIMER
This project is developed for educational and demonstration purposes. The health status and alerts provided by the system should not be considered a medical diagnosis. Users should consult a qualified healthcare professional for medical advice.
